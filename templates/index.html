epaData

EPA Data Management, Evaluation & Visualization

A unified platform for retrieving, validating, storing, exploring, and downloading environmental data from EPA CAMPD and related sources.

Current Data Coverage

EPA CAMPD annual records covering reporting years 2020–2024, with EPA TRACI 2.2 reference factors.

Data Sources

  • EPA CAMPD
  • EPA TRACI
  • User-uploaded datasets

Core Functions

  • Environmental-data retrieval
  • File upload & validation
  • Database storage & provenance
  • Search, filtering, ranking
  • CSV export

EPA CAMPD Retrieval

Retrieve environmental records directly from EPA CAMPD using server-side API calls.

Upload Data

Upload CSV or Excel files. The system validates schema, detects missing values, and reports data quality.
